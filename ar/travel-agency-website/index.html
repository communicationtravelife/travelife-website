إدارة الموقع

المحتوى والصفحات والتصميم والحجوزات: كل شيء يُدار من لوحة تحكم Travelife، دون نظام إدارة محتوى خارجي.

محتوى السفر

إدخال بسيط لمحتوى رحلاتكم

إدارة محتوى موقع وكالة الأسفار الإلكتروني أمر بسيط. فمن واجهة واضحة، تضيفون الرحلات والجولات ووصف الوجهات والصور أو المقالات.

ينسّق الموقع تلقائياً ما تدخلونه: فتُعرض عروضكم دائماً بشكل احترافي. وتحدّثون منتجاتكم بوتيرة أكبر، فيتحسن ظهوركم في محركات البحث.

التخصيص

تخصيص بسيط وشامل لموقعكم الإلكتروني

مع Travelife، تنشئون موقع وكالة الأسفار وتخصّصونه دون كفاءات تقنية ودون نظام إدارة محتوى خارجي مثل WordPress.

Theme Builderاختاروا القالب، وغيّروا الألوان، واضبطوا القائمة وتذييل الصفحة (footer)، وشاهدوا النتيجة مباشرة.
Menu Builderأنشئوا قوائم التنقل ورتّبوها بنقرات قليلة.
وحدات مدمجةعرض شرائح ومولّد نماذج ووحدات أخرى جاهزة للاستخدام.
Page Builder وSEO

محرر بسيط لإدارة محتوى موقعكم

مع Page Builder، تبنون كل صفحة بإضافة الكتل التي تختارونها: رحلات أو محركات بحث أو نماذج أو محتوى تسويقي.

تتيح لكم أدوات تحسين محركات البحث (SEO) المدمجة ضبط عنوان كل صفحة ووصفها ومحتواها. وبذلك يصبح موقعكم أكثر ظهوراً على Google.

الطلبات والحجوزات

إدارة مبسَّطة لطلباتكم وحجوزاتكم

هل ما زلتم تتابعون طلبات الحجز على Excel؟ مع المدير المدمج، يُسجَّل كل طلب تلقائياً في لوحة التحكم لديكم. توفرون الوقت وتتابعون كل شيء في مكان واحد، بطريقتكم.

التصميم

تصميم أنيق وعصري يُبرز رحلاتكم

كم تكلفة إنشاء موقع إلكتروني لوكالة أسفار مع Travelife؟

تقدّم Travelife ثلاث باقات معلنة. باقة Travelife Starter بسعر 99 € شهرياً، إضافة إلى 500 € رسوم إعداد: وهي مناسبة للوكالات التي تبيع منتجاتها الخاصة (جولات، عقود فندقية مباشرة، أنشطة). وباقة Travelife Advanced بسعر 399 € شهرياً، إضافة إلى 1500 € رسوم إعداد، وتشمل 2 API (تدفق فنادق واحد، تدفق طيران واحد)، ووحدة الباقات السياحية، ومن 6 إلى 8 ساعات من التدريب. أما عرض Premium / Enterprise فيُحدَّد بناءً على عرض سعر. لا تقتطع Travelife أي عمولة على المبيعات المحققة عبر موقعكم. تجدون التفاصيل في صفحة أسعار موقع B2C.

كم من الوقت يستغرق إطلاق موقع إلكتروني لوكالة أسفار؟

توقعوا نحو أسبوعين. Travelife حل جاهز للاستخدام مصمم خصيصاً لوكالات الأسفار ومنظمي الرحلات: لا حاجة لكتابة دفتر شروط ولا لشرح مهنة السياحة لمزوّد خدمة عام. تهيّئ فرقنا اسم النطاق، وتدمج شعاركم وهويتكم البصرية، ثم تدرّبكم على الأداة (انظروا المرافقة). يصلكم الموقع بكل الوظائف اللازمة لإدارة عروضكم وحجوزاتكم وعملائكم، ويمكنكم بعدها إضافة رحلاتكم وجولاتكم بالوتيرة التي تناسبكم من لوحة التحكم.

هل أحتاج إلى WordPress أو كفاءات تقنية لإدارة موقع وكالة الأسفار؟

لا. يُدار موقع Travelife دون نظام إدارة محتوى خارجي مثل WordPress ودون مهارة تقنية. يتيح Theme Builder اختيار القالب وتعديل الألوان والقائمة وتذييل الصفحة مع مشاهدة النتيجة مباشرة. وينظّم Menu Builder التنقل، ويبني Page Builder كل صفحة بإضافة وحدات: رحلات أو محركات بحث أو نماذج أو محتوى تسويقي. وتُنسَّق الرحلات والجولات والصور والمقالات التي تدخلونها تلقائياً. وتتيح أدوات SEO المدمجة ضبط عناوين كل صفحة ووصفها.

أي باقة أختار لموقع وكالتي: Starter أم Advanced أم Premium؟

يتوقف ذلك على نموذج أعمالكم. باقة Travelife Starter مثالية للخبراء المحليين ووكالات الاستقبال التي تُبرز منتجاتها الخاصة دون الاعتماد على واجهات API خارجية. وباقة Travelife Advanced موجّهة لوكالات السفر الخارجي وOTA التي ترغب في ربط مزوّديها وأتمتة مبيعاتها عبر تدفقات API للطيران والفنادق. أما Premium / Enterprise فمصمَّمة للشبكات الكبرى ومنظمي الرحلات: وصول غير محدود إلى Hub API (GDS Amadeus، GDS Sabre، Travelgate، بنوك فنادق متعددة)، وخوادم مخصصة، ودعم ذو أولوية 24/7. ويمكن الانتقال من باقة إلى أخرى.
