What's new in the "Manage" commercial management software

Dashboard: personalized access for efficient management. Travelife software has recently updated its dashboard to offer access…

TBy the Travelife team October 13, 2023 6 min read

In brief: the update to Manage, Travelife's business management software, brings six new features: a dashboard adapted to each agent's permissions, personalized notifications in the CRM, files per action for reconciling sales and purchases, more flexible invoicing (with or without VAT and margin), credit note and refund management, and an XML API connection with Air Arabia (Accelaero).

Travelife's Manage business management software is evolving to simplify the daily work of travel agencies. Here are the main new features of this update, module by module.

1. Dashboard

Personalized access for efficient management

Travelife software recently updated its dashboard to offer personalized access based on each agent's permissions. Administrators now have global, full access to the data, while agents have restricted access, limited to the information they need to carry out their tasks.

This update provides better control over access to sensitive data and ensures greater security of each customer's information. Travel agency managers can therefore rest assured that their data is protected.

2. CRM (customer relationship management)

Stay informed at all times with notifications

Travelife software recently added a new update to its CRM, which lets you create personalized notifications based on the bookings or files you follow. These notifications keep you informed in real time of important events related to your business, for example the cancellation of an optional booking.

Thanks to this feature, you can react quickly and effectively to changes that affect travel plans, and thus avoid unpleasant situations with your customers.

3. Organization and reconciliation

Optimize your cash flow management

Travelife software has recently improved several features to make it easier to organize and reconcile sales and purchases. One particularly useful feature is the ability to create files per action, which lets you track transactions better and match them quickly and easily.

This feature greatly simplifies the work of travel managers and accountants, allowing them to manage their company's finances more efficiently.

4. Invoices and accounting

Invoice generation

Travelife software is constantly evolving to meet the needs of tourism professionals. Recently, updates were made to invoicing and accounting:

  • Invoices and orders: it is now possible to create one invoice for several orders, or several invoices for a single order. Example: for a PNR booking for two people who want the invoice for each ticket issued in the name of a different company, you can create an invoice for each payment.
  • VAT and margin: it is now possible to generate invoices with or without VAT and margin. This option is very useful for accounting, but also for customers with specific needs. To learn more, see our page on VAT on margin for travel agencies.

5. Credit note and refund management

Make financial transactions easier to manage

Travelife recently received new updates concerning the management of credit notes and refunds. It is now possible to create a credit note or a refund linked to a customer invoice. This feature lets users manage their transactions more easily and maintain better relationships with their customers.

6. API connections

Simplify your booking process

Users can now connect Air Arabia (Accelaero) via XML directly to their management application. This new feature saves them time and optimizes their work by eliminating tedious manual steps.

Better handle your customers' requests

In addition, it is now possible to add an extra bag to bookings. This feature makes it easier to meet customers' needs by automating the work done by the travel agent.

More powerful software serving agencies

Travelife software has become more powerful thanks to these new updates. The ease of use of these features lets travel agents focus on their core activities while automating their management process. With these changes, Travelife adapts to its users' needs and continues to offer innovative solutions to make their work easier.

The CRM has continued to evolve since then: discover, for example, CRM pipelines for travel agencies.

FAQ

What is Manage in Travelife?

Manage is Travelife's business management software for travel agencies. It includes the dashboard, CRM, organization and reconciliation of sales and purchases, invoicing and accounting, credit note and refund management, and API connections with suppliers such as Air Arabia (Accelaero).

Can you issue several invoices for the same booking?

Yes. Since this update, Manage lets you create one invoice for several orders or several invoices for a single order. For example, for a PNR with two passengers whose tickets must each be invoiced to a different company, the agency can issue one invoice per payment. Invoices can also be generated with or without VAT and margin.

How does the dashboard protect sensitive data?

The dashboard now adapts to each user's permissions. Administrators have global, full access to the data, while agents only access the information needed for their tasks. This restriction improves access management and strengthens the security of each agency customer's information.
